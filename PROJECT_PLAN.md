# One-week execution plan

## Day 1
- Create the private GitHub repository.
- Add the project scaffold.
- Download and inspect the two raw data files.
- Run the feature-generation script.

## Day 2
- Train all classification and regression models.
- Inspect class distribution.
- Inspect confusion matrices, Kappa, AUROC, RMSE and R².

## Day 3
- Tune random-forest depth and number of trees.
- Tune the neural network if time permits.
- Record experiments and keep the final configuration reproducible.

## Day 4
- Run the full pipeline from a clean virtual environment.
- Verify the Streamlit demo.
- Generate final figures.

## Day 5
- Prepare the two-page PDF.
- Prepare the presentation.
- Split demo and explanation responsibilities between both members.

## Day 6-7
- Rehearse the live demo.
- Re-run everything from the README.
- Clean the repository.
- Verify faculty/TA access.
